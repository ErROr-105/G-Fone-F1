# G-Fone F1

프라이버시와 수리 가능성을 중시하는 애호가를 위한 보안 스마트폰 컨셉.

![G-Fone F1 Render](Assets/G-Fone%20Render%206%20view.png)

## 이것은 무엇인가?
G-Fone F1은 **제품이 아니며**, **제조 지침도 아닙니다**. 토론, 비판, 개선을 위해 공개된 엔지니어링 아이디어입니다.

- **목표:** 사용자 데이터에 대한 최대 통제권.
- **철학:** 접착제 없는 설계(glue-free), 높은 수리 가능성, 생성형 AI 배제, 정직한 사양.
- **시장:** 니치 시장, 러시아 외. 대중 시장이 아님.

## 주요 기능
- **배터리:** 5S1P, 46.25 Wh (3.7 V 기준 12,500 mAh 상당).
- **디스플레이:** 7인치 LTPS IPS QHD.
- **SMD 버튼:** 카메라/마이크 물리 전원 차단 + RGB 표시(충전/온도).
- **냉각:** 7075-T6 알루미늄, 3중 베이퍼 챔버, 핀, MEMS 마이크로펌프 *(컨셉)*.
- **OS:** LineageOS 기반, GApps 없음.
