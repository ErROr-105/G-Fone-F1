# G-Fone F1

A concept for a privacy-focused, repairable smartphone designed for enthusiasts.

![G-Fone F1 Render](Assets/G-Fone%20Render%206%20view.png)

## What is this?
G-Fone F1 is **not** a product and **not** a manufacturing guide. It is an engineering idea published for discussion, critique, and improvement.

- **Goal:** Maximum user control over data.
- **Philosophy:** Glue-free, high repairability, no generative AI, honest specifications.
- **Market:** Niche, outside Russia. Not mass-market.

## Key Features
- **Battery:** 5S1P, 46.25 Wh (equivalent to 12,500 mAh at 3.7 V).
- **Display:** 7" LTPS IPS QHD.
- **SMD Button:** Physical kill-switch for cameras/microphones + RGB indication (charge / temperature).
- **Cooling:** 7075-T6 aluminum, triple vapor chamber, fins, MEMS micropumps *(concept)*.
- **OS:** LineageOS-based, no GApps.
