# CHANGELOG

История изменений концепта G-Fone F1. Ранние версии (до Beta 3) не публикуются.

## Beta 6.3.7

- **USB Host Storage: гибкость на стороне пользователя** — без microSD; любой USB SSD; в комплекте USB→SATA с питанием; устройство как инструмент, не appliance.
- **eSIM: Privacy-First Control** — только activate/deactivate; удаление/правка/телеметрия только с явного согласия; локальный immutable log; без скрытых действий оператора.
- **Why No microSD?** — стандарты (USB), ремонтопригодность, 256 ГБ UFS 4.0 only внутри.

## Beta 6.3.6

- **Беспроводной зарядки нет** — КПД в разы ниже; ЭМП портит компас; нагрев опасен для АКБ 5S1P (*под горелку — живого не останется*).
- **eSIM полностью независим от экосистем** (Apple/Google/OEM).

## Beta 6.3.5

- **Механических слотов SIM и microSD нет** — **eSIM only**.
- **Внешние диски любого объёма** через USB host; **USB → SATA с питанием** в комплекте.

## Beta 6.3.4 — 6.3

См. полную историю в репозитории.

Ранние версии (Beta 1, Beta 2) не публикуются.
