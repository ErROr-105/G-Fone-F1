# CHANGELOG

История изменений концепта G-Fone F1. Ранние версии (до Beta 3) не публикуются: часть решений пересмотрена, часть снята как нереализуемая.

## Beta 6.3.2

- **BMS / балансировка 5S1P:** **активная** балансировка (перенос заряда) — базовый обязательный уровень; пассивная (bleed) — не baseline.

## Beta 6.3.1.2

- **Перемычки** вместо «12 рёбер»: без фиксированного числа; вид как одна ровно ниже SMD; алмазная решётка без пересечений; площадь контакта с воздухом по панели **~+25–35%** (оценка).

## Beta 6.3.1.1

- **Дроссель фильтра** — в телефоне (не во внешнем БП).
- **БП / charge path** — под пакет **18.5 В (5S1P)**, не под классические **3.7 В** single-cell.

## Beta 6.3.1

- **Стальное кольцо в корпусе** — посадка для **активного охлаждения на магнитах** (съёмный cooler).

## Beta 6.3

- **BMS / балансировка 5S1P:** пассивная балансировка (bleed) — базовый обязательный уровень; активная — опциональная high-end ревизия.
- **Уточнение:** pack-level PTC ≠ балансировка ячеек; мониторинг V/T по каждой из 5 банок; OV/UV/OT/OC/short.
- Документация: HARDWARE / OneinOne.

## Beta 6

- **X-Cross:** описание — внутренняя металлическая деталь-крестик для удержания призматических ячеек 5S1P.
- **PTC pack-level:** PTC-плёнка на уровне пакета (защита от холода); cell-level для 5S1P бессмысленен (последовательный пакет = один электротепловой узел).
- **Напальчники** из обычной ткани в комплекте: алюминий 7075 — «безумец» по теплоотводу; мера безопасности при обращении без чехла.
- **Чехол:** рамка с хватом; в комплекте колпаки для камер из силикона средней цены (антицарапалка).

## Beta 5.1

- **Экран:** 7″ → **6.77″** LTPS IPS QHD.
- **Основная камера:** Sony **IMX903** (было IMX907).
- **MEMS / Anti-Burn:** конкретная модель **xMEMS Lab XMC-2400** — 3 В, 30 мВт (насос) / **70 мВт с драйвером**; без абстрактного диапазона мощности.
- **Лицензии:** изменения ядра Linux — **GPLv2-only** (GPLv3 с ядром несовместим); userspace проекта — GPLv3; база LineageOS/AOSP — преимущественно **Apache 2.0** — совместима с GPLv3, но **смешение лицензий не отменяет оригинал** (Apache остаётся Apache).
- **NOTICE.md:** полный текст NOTICE из LineageOS `android_frameworks_base` (атрибуция AOSP / Apache 2.0 §4(d)).
- **Документация:** обновлены блоки лицензий в SOFTWARE.md / LICENSE.md / OneinOne.*.

## Beta 5

- **Easter egg — Mindustry load arrows:** при открытии Mindustry, в момент загрузки самой игры, кнопка SMD 4020 + линии SK6812 повторяют анимацию загрузочных стрелок из середины горизонтали **в том же свете/цвете**, что на экране (не привязано к boot устройства).
- **Питание / PMIC:** частичная интеграция продвинутого multiphase digital buck-контроллера для hot rails SoC (CPU/GPU/NPU) плюс HV front-end для 5S1P 18.5 В; companion для остальных доменов.
- **Маркеры концепта:** пересмотрены (SoC/LPDDR6/UFS 5.0/MEMS — серийные; тройной VC, телескопическая антенна, рёбра — концепт/системная интеграция).
- **MEMS:** мощность драйвера в диапазоне 0.1–0.3 Вт (в Beta 5.1 заменено спецификацией XMC-2400).
- **Шифрование:** формулировка FBE (file-based encryption) вместо FDE.
- **Документация:** восстановлен русский OneinOne.md; синхронизация HARDWARE/OneinOne по RU/EN/ZH/KO.
