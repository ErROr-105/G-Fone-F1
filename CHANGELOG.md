# CHANGELOG

История изменений концепта G-Fone F1. Ранние версии (до Beta 3) не публикуются.

## Beta 6.3.11

- **DualBIOS:** secondary loader (не «USB из Boot ROM»); типично SPI NOR; **AVB / user keys** или explicit disable+warning; notify через **LED/USB**, не только экран.
- **RF path kill:** у кнопки явно — модем может сохранять **DMA к RAM**.
- Камеры: **quad-Bayer 50→~12.5 МП**.
- «Не российский рынок» убрано из блока «Что это» (остаётся в дисклеймере при необходимости).

## Beta 6.3.10

- PPS ~21 В; 1.6C + щадящий default; eUICC honesty; Apache↔GPLv2; SMD ≠ surface-mount.

## Beta 6.3.9

- UFS 5.0; DualBIOS (первая версия).
