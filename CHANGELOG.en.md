# CHANGELOG

History of changes to the G-Fone F1 concept. Early versions (before Beta 3) are not published.

## Beta 6.3.12

- **RF kill L1/L2:** L1 = path (required); L2 = rail **if** SoC/PMIC exposes a separate baseband/eUICC rail; else L1 only.
- **USB Host:** 2.5″ prefer **USB-C/PD**; 3.5″ needs 12 V; optional **signed storage** policy (with AVB external boot).
- **BMS:** documented IC (TI BQ-class / equiv.); **X-Cross** = cell mechanics only.

## Beta 6.3.11

- DualBIOS secondary loader + AVB; RF DMA caveat; binning 50→12.5.

## Beta 6.3.10

- PPS ~21 V; 1.6C + gentle default; eUICC honesty; Apache↔GPLv2.
