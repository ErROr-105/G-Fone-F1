# CHANGELOG

History of changes to the G-Fone F1 concept. Early versions (before Beta 3) are not published.

## Beta 6.3.9

- Internal storage: **UFS 5.0 256 GB** (UFS 4.0 removed).
- **DualBIOS:** spare boot chip (own firmware + SoC Boot ROM); on UFS failure — notify and offer to boot Android from an external disk if an image was written.

## Beta 6.3.8

- Threat model; split SMD (sensors + RF path kill); USB→SATA 2.5″/3.5″; calculated charge times; microSD = reliability/IP.
