# CHANGELOG

- eSIM: **eUICC/modem closed**; OS policy ≠ guarantee; “immutable” log without TEE/SE is not crypto-immutability.
- Licenses: Apache 2.0 **incompatible with GPLv2 if merged**; keep components **separate**; Apache OK with GPLv3.
- SMD = **Stop Meta Data** (not surface-mount); finger cots = 7075 thermal; 12.5 Ah = **calculation**.
