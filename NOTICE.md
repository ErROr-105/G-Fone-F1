# NOTICE

This file reproduces the **NOTICE** text as shipped with the LineageOS / AOSP base stack.

**Source:** [LineageOS/android_frameworks_base](https://github.com/LineageOS/android_frameworks_base) — file `NOTICE` (branch `lineage-23.0`).

LineageOS does not publish a single project-wide root `NOTICE` separate from AOSP: the distribution is built from many repositories, each with its own `NOTICE` / license files. The `frameworks/base` NOTICE is the primary Android platform attribution notice (Apache License 2.0 §4(d) and related third-party notices) inherited by LineageOS-based builds, including the G-Fone F1 software concept.

**Note:** Mixed licenses in the full tree (kernel GPLv2-only, Apache 2.0 userspace, etc.) are not replaced by this file. See `LICENSE.md` and `SOFTWARE.md`.
