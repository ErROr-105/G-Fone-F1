# G-Fone F1

面向隐私与可维修性爱好者的安全智能手机概念。

![G-Fone F1 Render](Assets/G-Fone%20Render%206%20view.png)

## 这是什么？
G-Fone F1 **不是**产品，也**不是**生产说明书。这是一个公开发布的工程理念，供讨论、批评和改进。

- **目标：** 用户对数据的最大控制权。
- **理念：** 无胶水设计、高可维修性、无生成式 AI、诚实的规格参数。
- **市场：** 小众市场，不面向俄罗斯。非大众市场。

## 主要特性
- **电池：** 5S1P，46.25 Wh（相当于 3.7 V 下 12500 mAh）。
- **屏幕：** 7 英寸 LTPS IPS QHD。
- **SMD 按钮：** 物理切断摄像头/麦克风电源 + RGB 指示（充电/温度）。
- **散热：** 7075-T6 铝合金、三层均热板、散热鳍片、MEMS 微泵 *（概念）*。
- **系统：** 基于 LineageOS，无 GApps。
