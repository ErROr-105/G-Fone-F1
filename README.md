# G-Fone F1

Концепт защищённого смартфона для энтузиастов приватности и ремонтопригодности.

## Что это
G-Fone F1 — не продукт и не инструкция к производству. Это инженерная идея, выложенная в открытый доступ для обсуждения, критики и улучшения. 

- **Цель:** максимум контроля пользователя над данными.
- **Философия:** glue-free, ремонтопригодность, отсутствие генеративного AI, честные спецификации.
- **Рынок:** нишевый, вне РФ. Не масс-маркет.

## Ключевые фичи
- **АКБ:** 5S1P, 46.25 Вт·ч (эквивалент 12500 мА·ч при 3.7 В).
- **Экран:** 7" LTPS IPS QHD.
- **Кнопка SMD:** физическое отключение камер/микрофонов + RGB-индикация (заряд/температура).
- **Охлаждение:** алюминий 7075-T6, тройной VC, оребрение, MEMS-микронасосы *(концепт)*.
- **ОС:** LineageOS-based без GApps.
