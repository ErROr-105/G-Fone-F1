## Что это
G-Fone F1 — концепт защищённого смартфона для **технарей**. Не продукт, не оферта.

## Основные характеристики
- **SoC:** MediaTek Dimensity 9600 Pro, 2 нм. LPDDR6 + UFS 5.0.
- **Память:** 16 ГБ LPDDR6 + **256 ГБ UFS 5.0** (без microSD).
- **Экран:** 6.77" LTPS IPS QHD.
- **АКБ:** 5S1P, ~18.5 В номинал / ~21 В full, 46.25 Вт·ч. X-Cross (механика). BMS active + шунт + NTC на документируемом IC.
- **Зарядка:** до 80 Вт, USB PD PPS (~21 В). ~1.6C → щадящий default 40–50 Вт. Без wireless.
- **Связь:** eSIM only. USB Host + USB→SATA.
- **Цена:** €3200.

### DualBIOS
SPI NOR + secondary loader; AVB user-keys или explicit warning; notify LED/USB.

### eSIM Privacy-First
Userspace activate/deactivate; eUICC/модем закрыты.

### Камеры
| Модуль | Спека |
|--------|--------|
| Основная | Sony LYTIA 720 |
| Теле | ~70 мм, 50 МП, f/1.8, OIS, IMX858-класс |
| Ультраширик | IMX858, ~14 мм, f/2.2, 50 МП |

HDR Stacking — userspace GPLv3, без проприетарного AI.

### SMD = Stop Meta Data
Левый: питание камер/мик/акселерометра. Правый: RF L1 path / L2 rail if available.

### Mindustry load-arrows
Фича open-source игры: подсветка повторяет load-стрелки.
